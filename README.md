# OhO

Nos outils, à deux. Une PWA mobile d'abord où Aurélien et Auriane partagent leurs outils du quotidien dans un espace commun : Courses, Voyages, À regarder et Dépenses.

## Cadrage

| Document | Contenu |
|---|---|
| [`docs/cadrage/PLAN.md`](docs/cadrage/PLAN.md) | Plan de projet : vision, outils, architecture, découpage en lots |
| [`docs/DECISIONS.md`](docs/DECISIONS.md) | Toutes les décisions du lot 0 (produit, stack, modèle de données, design) |
| [`docs/cadrage/modele-donnees.html`](docs/cadrage/modele-donnees.html) | Modèle de données détaillé (24 tables, accès, décisions) |
| [`docs/cadrage/maquettes-app.html`](docs/cadrage/maquettes-app.html) | Première maquette des écrans |

Les deux fichiers HTML s'ouvrent directement dans un navigateur.
